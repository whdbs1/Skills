내장 함수

abs(): 절댓값
round(): 반올림
divmod(): 2차원리스트

all(): 모든값 True일 경우
any(): 하나의 값 True일 경우
bool(): True인지 False인지 구별

enumerate(): for 사용 시 요소와 인덱스 값을 동시에 추출
range(): 정수 범위 생성
len(): 리스트의 인자의 개수 or 글자의 길이

input(): 값을 입력받음
print(): 출력

int(): 정수 데이터로 변환
str(): 문자 데이터로 변환
list(): 리스트 생성 or 자료형을 리스트로 변환
tuple(): 튜플 생성 or 자료형을 튜플로 변환
dict(): 딕셔너리 생성 or 자료형을 딕셔너리로 변환
set(): 정렬
